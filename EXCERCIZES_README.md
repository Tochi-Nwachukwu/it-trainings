## Where to practise online

- **HackerRank** — hackerrank.com/domains/python (structured, beginner friendly)
- **LeetCode** — leetcode.com (start with "Easy", great for interviews)
- **Codewars** — codewars.com (gamified, 8kyu is easiest)
- **Exercism** — exercism.org/tracks/python (free mentoring)
