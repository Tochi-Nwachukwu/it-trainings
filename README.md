## 📏 The Rules of This Course

1. **Type every example yourself.** Copy-pasting teaches you nothing. Typing builds muscle memory.
2. **Break things on purpose.** Delete a colon. Misspell a variable. Read the error. Errors are teachers, not failures.
3. **Do the activities before opening the solutions.** Struggling for 5 minutes teaches more than reading an answer for 5 seconds.
4. **Ask questions early.** If lesson 13 is confusing, the problem is usually something from lesson 11.

## 🆘 Getting Help

| Problem | What to do |
|---------|------------|
| Something won't install | See [SETUP.md](SETUP.md) troubleshooting section |
| Code gives an error | Read the **last line** of the error first — it names the problem |
| Concept doesn't click | Go back one lesson; it usually builds on something earlier |
| Still stuck | Bring it to class or post in the group chat |
